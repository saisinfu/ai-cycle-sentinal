# AI-Cycle Sentinel

แอปมือถือ Android ติดตามวัฏจักรการลงทุน AI และแนวทางจัดพอร์ต KLAC / AVGO / ETN

## ดาวน์โหลดแอป
เปิดลิงก์นี้ในมือถือ แล้วแตะไฟล์ **AI-Sentinel.apk** ในส่วน Assets
👉 https://github.com/saisinfu/ai-cycle-sentinal/releases/latest

## ข้อมูลอัปเดตอย่างไร
- Claude ค้นข้อมูลตลาดจริงทุกวัน แล้วบันทึกลง `data/readings.json` ในโปรเจกต์นี้
- แอปดึงไฟล์นั้นทุกครั้งที่เปิดหรือดึงหน้าจอลง ถ้าไม่มีอินเทอร์เน็ตจะแสดงข้อมูลที่บันทึกไว้ล่าสุด

## โครงสร้าง
| โฟลเดอร์ | คืออะไร |
|---|---|
| `app/` | โค้ดแอป Flutter (คำนวณคะแนน 5 สัญญาณ, ช่วงกันชน ±3, กฎจัดพอร์ต) |
| `data/readings.json` | ข้อมูลรายวัน |
| `.github/workflows/build-apk.yml` | GitHub สร้างไฟล์ APK ให้อัตโนมัติเมื่อโค้ดเปลี่ยน |

`app/signing/debug.keystore` คือกุญแจลงชื่อแอป ใช้ชุดเดิมทุกครั้งเพื่อให้ติดตั้งเวอร์ชันใหม่ทับของเดิมได้ เป็นแอปใช้ส่วนตัว อย่าติดตั้ง APK ที่ได้มาจากที่อื่นนอกจากหน้า Releases ของโปรเจกต์นี้

> ผลลัพธ์มาจากกฎที่ตั้งไว้ล่วงหน้า เป็นเครื่องมือเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน
